# 실적·손익·원가관리 업무 일정표

GitHub Pages 웹앱 · 업무 데이터는 GitHub 비공개 저장소에만 저장 (변경할 때마다 자동 저장 · 전체 이력 보관)

## 저장 구조
| 위치 | 내용 | 공개 여부 |
|---|---|---|
| `main` 브랜치 `docs/index.html` | 앱 화면 (업무 원문 없음) | 사이트로 공개 |
| `main` 브랜치 `docs/key.json` | 열쇠 파일 = 비밀번호로 암호화한 GitHub 토큰 | 사이트로 공개 (암호문) |
| `data` 브랜치 `data.json` | 업무 데이터 (암호문) · 저장 1회 = 기록 1건 | 비공개 저장소 내부 |
| 브라우저 | 서버에 아직 못 보낸 변경만 임시 보관 → 저장 성공 시 즉시 삭제 | — |

※ GitHub Pages는 `index.html` 파일명을 요구하므로 파일명 규칙(C-·일시) 적용 제외

## 사용 흐름
1. 사이트 접속 → **비밀번호 입력** (어느 기기든 비밀번호만)
2. 열쇠 파일의 토큰을 풀어 GitHub에서 최신 데이터 불러오기
3. 변경 → 1~2초 뒤 **자동 저장** · 상단 상태: `● 저장 대기` → `⏳ 저장 중…` → `☁️ 저장됨 HH:MM`
4. 다른 기기에서 바꾼 내용: 창으로 돌아오면 자동 반영

| 상황 | 동작 |
|---|---|
| 저장 실패 (네트워크) | 3회 자동 재시도 → `⚠ 저장 실패 · 다시 시도` · 변경은 브라우저에 임시 보관 → 다음 접속 시 보내기 확인 |
| 저장 전 창 닫기·잠금 | 경고 |
| 두 기기 동시 수정 | 선택 창 [이 화면 내용으로 저장] / [서버 내용 불러오기] · 두 내용 모두 이력에 보존 |
| 토큰 만료 | `⚠ 토큰 만료` → 비밀번호 + 새 토큰 입력 (모든 기기에 적용) |
| 되돌리기 필요 | ↶ ↷ (이번 접속 중) · ☰ 메뉴 **🕘 변경 이력** (GitHub 전체 기록, 시점 선택 → 복원) |

## 데이터 암호화
| 항목 | 방식 |
|---|---|
| 암호화 | AES-256-GCM (브라우저 내장 Web Crypto) |
| 키 생성 | 비밀번호 + 무작위 salt → PBKDF2-SHA256 600,000회 |
| 암호화 대상 | 업무 데이터 · 토큰(열쇠 파일) · 백업 파일 |
| 평문 노출 | `updatedAt`(최종 저장 시각)만 |
| 비밀번호 보관 | 어디에도 저장 안 함 → **분실 시 복구 불가** |

- 비밀번호 권장: 12자 이상 · 다른 서비스와 다른 문구 (공개 열쇠 파일 보호)
- 🔑 비밀번호 변경: 데이터·열쇠 파일을 새 비밀번호로 재암호화해 저장 · 이전 기록은 변경 이력에서 이전 비밀번호로 열람
- 토큰: Fine-grained · 저장소 `notion` 1개 · Contents: Read and write

## 배포
- Settings → Pages → Branch `main` · 폴더 `/docs`
- Private 저장소의 Pages는 GitHub Pro 이상 요금제 필요

## 캘린더 사용법
| 동작 | 결과 |
|---|---|
| 업무 클릭 (모바일: 짧게 탭) | 완료 토글 |
| 업무 드래그 (모바일: 길게 눌러 이동) | 일자 이동 · 정례 업무는 영업일 차이만큼 기간 전체 이동 (이번 달만, ↺로 복귀) · SPOT은 아무 날짜 |
| 빈 곳 클릭 | 업무 추가 · 내 연차(연차/오전반차/오후반차) · 회사 휴무 등록·삭제 |
| 업무에 마우스 올리기 → ✎ 클릭 (모바일: 길게 눌렀다 그대로 떼기) · 체크리스트 업무명 클릭 | 수정·메모 팝업 |

| 수정·메모 팝업 | SPOT 업무 | 정례 업무 |
|---|---|---|
| 업무명 | 수정 가능 | 읽기 전용 (표준 타임테이블에서 수정) |
| 카테고리 · 날짜 | 수정 가능 (다른 달 날짜 → 그 달로 이동) | 이달 일정 표시 |
| 완료 | 체크 | 체크 |
| 메모 | 업무별 메모 | 이달 메모 + 이전 달 메모 조회 (최신순) |
| 삭제 | 가능 (↶로 복구) | — |
- 메모가 있으면 달력 📝 · 체크리스트에 첫 줄 미리보기

| 셀 배경 | 의미 |
|---|---|
| 흰색 | 영업일 |
| 분홍 | 일요일·공휴일 |
| 회청 | 토요일 |
| 회색 빗금 | 회사 휴무 → 영업일 계산에서 제외 |
| 초록 / 반쪽 초록 | 내 연차 / 반차 → 영업일 영향 없음, 마감일과 겹치면 「연차일 마감」 경고 |

## 표준 타임테이블 사용법
| 동작 | 결과 |
|---|---|
| 막대 가운데 드래그 | 기간 유지한 채 이동 |
| 막대 양 끝 드래그 | 시작 / 종료 영업일 조정 |
| 막대·업무명 클릭 | 편집 팝업 (카테고리·업무명·영업일·진행 형태·완료 액션·설명·삭제·복제) |
| 빈 칸 클릭 · 그룹 [+ 업무 추가] | 새 업무 추가 |
| 터치 | 길게 누른 뒤 드래그 · 바로 밀면 스크롤 |

## 되돌리기 / 다시 실행
- 상단 ↶ ↷ 버튼 · Ctrl+Z / Ctrl+Y(또는 Ctrl+Shift+Z) · 모든 메뉴 공통 · 최대 100단계
- 새로고침·잠금 시 이력 초기화

## PDF 출력
| 메뉴 | 버튼 위치 | 용지 | 출력 범위 | 기본 파일명 |
|---|---|---|---|---|
| 이달의 일정 | 달력 우측 상단 [📄 PDF 출력] | A4 가로 1쪽 | 달력만 (업무명 줄바꿈 전체 표시) | `C-M월달력_YYMMDD_HHMM` |
| 표준 타임테이블 | 탭 상단 [📄 PDF 출력] | A4 세로 | 요약 · 타임라인 · SPOT · 분기 · 연간 (편집기 제외) | `C-표준타임테이블_YYMMDD_HHMM` |
- 인쇄 창 대상 **PDF로 저장** → 저장 · 글자는 텍스트로 저장 (선명 · 검색 가능)
