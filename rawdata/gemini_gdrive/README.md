# 손익·원가 월간 실사 캘린더 & 표준 업무 매뉴얼 웹앱

GitHub Pages를 통해 서버 지연 없이 즉시 동작하는 손익·원가 일정 관리 및 표준 업무 매뉴얼 웹 애플리케이션입니다.

## 🚀 1분 배포 방법 (GitHub Pages)
1. GitHub에서 새 저장소(Repository)를 생성합니다.
2. 이 패키지에 포함된 **`index.html`** 과 **`data.json`** 두 파일을 저장소에 업로드(Drag & Drop)하고 **Commit changes**를 누릅니다.
3. 저장소 상단 메뉴의 **Settings** → 좌측 **Pages** 메뉴로 이동합니다.
4. **Build and deployment** 아래의 **Branch**를 `main` (폴더는 `/(root)`)으로 선택하고 **Save**를 누릅니다.
5. 약 30초~1분 뒤 생성된 `https://<계정명>.github.io/<저장소명>/` 주소로 접속하시면 바로 사용하실 수 있습니다.

## ☁️ 여러 PC·모바일 간 데이터 동기화 방법
* 웹앱 우측 상단의 **[☁️ GitHub 동기화 설정]** 버튼을 눌러 본인 계정명, 저장소명, GitHub Personal Access Token(`repo` 권한)을 1회 입력해 두면, 이후 **[⬆️ GitHub에 즉시 저장]** 버튼 하나로 언제든 저장소의 `data.json` 파일에 변경사항이 직접 커밋됩니다.
